# MeowBox

Free, no-ads file hosting for the web.

- Up to 50MB per file
- Direct links - hotlink anywhere
- Permanent or expiring links (2 hours / 24 hours / 2 days)
- Albums and delete control with a free account
- Anonymous uploads, no account needed
- Catbox-style API for automation
