# MeowBox

**MeowBox file sharing** — free, no-ads file hosting with direct links.

- Up to 25 MB per file
- Direct links — hotlink anywhere (blogs, forums, chats)
- Permanent or expiring links (2 hours / 24 hours / 2 days / 7 days)
- Image upload and photo hosting — JPG, PNG, GIF, WebP
- Video, audio, PDF and archive sharing
- Albums and delete control with a free account
- Anonymous uploads — no account needed
- Automatic malware scanning on every upload
- Simple REST API for automation

Website: https://meowbox.dpdns.org
FAQ: https://meowbox.dpdns.org/faq
